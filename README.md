# JavaScript & DOM Fundamentals

Pamata interaktīvu JavaScript uzdevumu kolekcija, kas aptver DOM manipulācijas, lokālo krātuvi, masīvu metodes (`filter`, `forEach`), notikumu klausītājus un asinhronus HTTP pieprasījumus, izmantojot `async/await`.

## 🛠 Concepts Covered:
- **DOM Manipulation:** Dynamically creating, updating, and removing HTML elements.
- **State & LocalStorage:** Persisting application state in browser storage (`JSON.stringify` / `JSON.parse`).
- **Array Methods:** Working with arrays using `filter()`, `forEach()`, and `splice()`.
- **Async JavaScript:** Using `fetch()` API with modern `async/await` syntax for HTTP requests.
- **Event Handling:** Working with `click`, `input`, and inline event listeners.

## 🚀 How to Run:
No installation required! 
1. Open `index.html` in any web browser.
2. Alternatively, use the **Live Server** extension in VS Code.
